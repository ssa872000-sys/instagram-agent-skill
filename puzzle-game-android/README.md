# Пятнашки — головоломка для Android

Классическая головоломка: расставь плитки с числами по порядку, сдвигая их в пустую клетку.

- Три размера поля: 3×3, 4×4, 5×5
- Счётчик ходов, таймер и рекорд для каждого размера (рекорды сохраняются между запусками)
- Управление нажатием или свайпом по плитке; можно сдвинуть сразу несколько плиток в ряду
- Каждая раскладка гарантированно решаема
- Работает без интернета

## Как получить APK

APK собирается автоматически на GitHub при каждом изменении в этой папке.

1. Откройте репозиторий на GitHub → вкладка **Actions** → **Build Android APK**.
2. Выберите последний успешный запуск (зелёная галочка).
3. Внизу страницы в разделе **Artifacts** скачайте `pyatnashki-apk` (это zip-архив).
4. Распакуйте архив — внутри `pyatnashki.apk`.

Запустить сборку вручную: **Actions → Build Android APK → Run workflow**.

## Как установить на телефон

1. Перекиньте `pyatnashki.apk` на телефон (или скачайте прямо на нём).
2. Откройте файл. Android попросит разрешить установку из этого источника — разрешите.
3. Нажмите **Установить**. Игра появится в меню как «Пятнашки».

## Как устроено

| Файл | Что внутри |
|---|---|
| `app/src/main/assets/index.html` | Вся игра (HTML + CSS + JavaScript) |
| `app/src/main/java/com/puzzle/game/MainActivity.java` | Android-оболочка: открывает игру на весь экран |
| `app/src/main/res/` | Название приложения, иконка, тема |
| `app/build.gradle` | Версия приложения (`versionCode`, `versionName`), ID пакета |

Игру можно открыть и проверить прямо в браузере компьютера — просто откройте `index.html`.

## Собрать локально

Нужны Android Studio (или Android SDK) и JDK 17:

```bash
cd puzzle-game-android
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Чтобы выложить в Google Play

Сейчас собирается отладочная (debug) версия — её можно ставить на телефоны и раздавать.
Для Google Play нужно:

1. Сменить `applicationId` в `app/build.gradle` на свой уникальный (например, `com.vashe_imya.pyatnashki`).
2. Создать ключ подписи и собрать подписанный `.aab` (`./gradlew bundleRelease`).
3. Зарегистрировать аккаунт разработчика Google Play (разовый взнос $25) и загрузить файл.
