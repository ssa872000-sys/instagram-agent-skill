# Пятнашки — головоломка для Android

Классическая головоломка: расставь плитки с числами по порядку, сдвигая их в пустую клетку.

- Три размера поля: 3×3, 4×4, 5×5
- Счётчик ходов, таймер и рекорд для каждого размера (рекорды сохраняются между запусками)
- Управление нажатием или свайпом; можно сдвинуть сразу несколько плиток в ряду
- Каждая раскладка гарантированно решаема
- Работает без интернета, без рекламы, не собирает данные

Проект готов к публикации в Google Play: Android 16 (API 36), файл `.aab`, подпись ключом загрузки, иконки, скриншоты, тексты и политика конфиденциальности.

## Что собирает GitHub

При каждом изменении в этой папке GitHub Actions (**Actions → Build Android app**) собирает:

| Артефакт | Что это | Для чего |
|---|---|---|
| `pyatnashki-test-apk` | `pyatnashki-test.apk` | Поставить на свой телефон и проверить. Называется «Пятнашки (тест)» и не мешает версии из Google Play |
| `pyatnashki-google-play-aab` | `pyatnashki-google-play.aab` | Загрузить в Google Play Console |

Артефакты скачиваются как zip-архив — распакуйте его. Файл `.aab` появляется, только когда заданы секреты с ключом подписи (шаг 1 ниже).

Номер версии (`versionCode`) растёт сам с каждой сборкой, поэтому Google Play всегда примет новый файл.

## Публикация в Google Play — по шагам

### 1. Один раз: ключ подписи в секреты GitHub

Google Play принимает только файлы, подписанные ключом загрузки. Ключ — это файл `upload-keystore.p12` и пароль к нему. **В репозиторий их класть нельзя** (он публичный), поэтому GitHub берёт их из секретов.

1. GitHub → репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
2. Создайте два секрета:

   | Name | Secret |
   |---|---|
   | `SIGNING_KEYSTORE_BASE64` | всё содержимое файла `SIGNING_KEYSTORE_BASE64.txt` (это файл ключа, записанный текстом) |
   | `SIGNING_PASSWORD` | содержимое файла `SIGNING_PASSWORD.txt` |

3. Запустите сборку заново: **Actions** → последний запуск → **Re-run all jobs**.

Свой ключ можно сделать и самому:

```bash
keytool -genkeypair -storetype PKCS12 -keystore upload-keystore.p12 -alias upload \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 upload-keystore.p12 > SIGNING_KEYSTORE_BASE64.txt   # текст для секрета
```

Псевдоним ключа (alias) должен быть `upload`, пароль хранилища и ключа — один и тот же.

> **Храните `upload-keystore.p12` и пароль в надёжном месте, не в репозитории.** Без них нельзя выпускать обновления. Если ключ потеряется, в Play Console можно запросить сброс ключа загрузки (Play Console → Тестирование и выпуск → Подпись приложений).

### 2. Аккаунт разработчика

[play.google.com/console](https://play.google.com/console) → зарегистрироваться как **личный аккаунт**, оплатить разовый взнос $25, подтвердить личность и телефон.

### 3. Создать приложение

**Все приложения → Создать приложение:** название `Пятнашки — головоломка`, язык по умолчанию — русский, тип — **Игра**, **Бесплатное**.

### 4. Контент приложения

Раздел **Контент приложения** (внизу меню). Готовые ответы — в [`store/listing-ru.md`](store/listing-ru.md). Ссылка на политику конфиденциальности — страница [`PRIVACY.md`](PRIVACY.md) на GitHub.

### 5. Страница в магазине

**Основная страница в Google Play:** тексты из [`store/listing-ru.md`](store/listing-ru.md), значок `store/icon-512.png`, баннер `store/feature-graphic.png`, скриншоты из `store/screenshots/`.

### 6. Закрытое тестирование — обязательно для новых личных аккаунтов

Google требует, чтобы перед выходом в открытый доступ **не меньше 12 тестировщиков** были подключены к закрытому тесту **14 дней подряд**.

1. **Тестирование → Закрытое тестирование → Создать трек**.
2. Добавьте тестировщиков (их адреса Gmail) — друзей, родных, коллег.
3. **Создать выпуск** → загрузите `pyatnashki-google-play.aab` → отправьте на проверку.
4. Отправьте тестировщикам ссылку для участия: им нужно принять приглашение и установить игру из Google Play.

### 7. Открытый доступ

Через 14 дней на **Панели управления** появится кнопка **Подать заявку на доступ к рабочей версии**. После одобрения создайте выпуск в **Рабочей версии** с тем же или новым `.aab`.

## Обновления

Измените игру → GitHub сам соберёт новый `.aab` с большим номером версии → загрузите его в новый выпуск в Play Console. Видимую версию (`versionName`) можно поменять в `app/build.gradle`.

## Как устроено

| Файл | Что внутри |
|---|---|
| `app/src/main/assets/index.html` | Вся игра (HTML + CSS + JavaScript). Можно открыть в браузере компьютера |
| `app/src/main/java/com/puzzle/game/MainActivity.java` | Android-оболочка: показывает игру на весь экран с учётом вырезов и системных панелей |
| `app/build.gradle` | ID приложения в Google Play (`io.github.ssa872000sys.pyatnashki`), версия, подпись |
| `app/src/main/res/` | Название, адаптивная иконка, тема |
| `store/` | Значок, баннер, скриншоты и тексты для страницы в Google Play |
| `PRIVACY.md` | Политика конфиденциальности |

## Сборка на компьютере

Нужны Android Studio (или Android SDK) и JDK 17. Для подписанного `.aab` положите `upload-keystore.p12` рядом с `settings.gradle` (git его не увидит):

```bash
cd puzzle-game-android
./gradlew assembleDebug                                 # тестовый APK
SIGNING_PASSWORD='пароль' ./gradlew bundleRelease       # подписанный .aab для Google Play
```
