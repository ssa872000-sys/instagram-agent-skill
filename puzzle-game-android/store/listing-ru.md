# Страница в Google Play — готовые тексты и ответы

Копируйте отсюда в Google Play Console.

## Основная информация

**Название приложения** (до 30 символов):

```
Пятнашки — головоломка
```

**Краткое описание** (до 80 символов):

```
Классическая головоломка: расставь плитки по порядку. Поля 3×3, 4×4 и 5×5.
```

**Полное описание** (до 4000 символов):

```
Пятнашки — классическая головоломка, знакомая многим с детства. Расставьте плитки с числами по порядку, сдвигая их в пустую клетку. Начать просто, оторваться сложно!

Что есть в игре:
• Три размера поля: 3×3 для разминки, 4×4 — классика, 5×5 — для настоящих мастеров
• Счётчик ходов и таймер
• Рекорд для каждого размера поля — попробуйте побить свой лучший результат
• Удобное управление: нажмите на плитку или смахните её. Можно сдвинуть сразу несколько плиток в ряду
• Плитки, которые стоят на своих местах, подсвечиваются зелёным
• Каждая раскладка гарантированно решаема
• Работает без интернета
• Без рекламы и без регистрации
• Не собирает никаких данных

Пятнашки тренируют логику, внимание и пространственное мышление. Отличный способ провести пару минут в дороге или в очереди.
```
